✈️ SKYPASS 바우처 사용 실적 통합 대시보드

(권종별, 지역별, PKG/HTL별, 팀별 사용 상세 내역)

1. 총 사용 건수 요약 실적

* 출발일 기준 / 금액 단위: 원 (공제마일: 마일)
구분 사용 실적 (출발일 기준)
사용건수 (건) 공제마일 정산금액 (원) 수익 (12%, 원)

※ 정산금액 = 양사부담금 적용금액 / ※ 수익 = 성인요금(수탁금)의 12% 산출 기준

2. 사용 건수 세부 분석 (권종 및 지역별)

1) 바우처 권종별 사용 건수 및 비중 (통합)

권종금월 건수금월 비중

2) 지역(노선)별 사용 건수

지역금월 건수금월 비중

3) 지역별 × 권종별 사용건수

4) 💡 프로모션 할인 바우처 세부 현황 (10%/5% 할인)

권종 구분표준 마일할인 적용 마일정상 건수할인 건수전체 건수할인 비중

3. 사용 실적 세부 (PKG/HTL)

ㅇ PKG / HTL 구분 실적

ㅇ PKG / HTL 지역별 사용 실적

4. 각 팀별 바우처 사용 실적

구분상품유형사용건수공제마일정산금액수탁금수익(12%)

월별 사용건수 및 정산금액 추이

선택 월 팀별 정산금액 비중
